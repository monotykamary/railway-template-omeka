# Omeka Classic on Railway

[![Deploy on Railway](https://railway.com/button.svg)](https://railway.com/deploy/omeka?referralCode=ZqgrJ0)

Deploy Omeka Classic 3.2.1 with generated administrator and database passwords, private MariaDB, persistent collection files, and daily backups.

Sign in at `/admin` as `admin` with `OMEKA_ADMIN_PASSWORD`. Use one application replica because uploaded files use an attached volume.

Upstream: https://github.com/omeka/Omeka/tree/v3.2.1 (GPL-3.0-or-later). Not affiliated with Railway.
